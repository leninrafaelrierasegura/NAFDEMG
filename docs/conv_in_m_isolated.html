Isolated rational approximation error in m

Last rendered: 28-10-2026

This experiment isolates the error introduced by the rational approximation of the discrete fractional operator. The rational solution is computed with the existing shifted sparse solver at every time step. Its reference is backward Euler with the exact fractional power of the same assembled FEM operator, evaluated through a complete numerical generalized eigendecomposition. No identity about projected continuum eigenfunctions is assumed.

1 The comparison

The physical equation is \[ u_t+\nu(\kappa^2-\Delta_\Gamma)^{\alpha/2}u=f, \qquad u_0=10e_5,\qquad f(t)=10\sin(\pi t)e_7. \] Both discrete evolutions receive the same initial vector, physical forcing load, diffusion coefficient, and interval-averaged sine forcing. For \(C=\texttt{graph\$mesh\$C}\) and \(L=\kappa^2C+G\), the full numerical eigensystem satisfies \[ LV=CV\Lambda,\qquad V^\top CV=I. \] The exact-discrete reference uses \[ U_h^{k+1}=V\operatorname{diag}\left( \frac{1}{1+\tau\nu\lambda_j^{\alpha/2}}\right) V^\top(CU_h^k+\tau F^{k+1}). \] The primary measured error is \[ E_{\mathrm{rat}}(m)=\left[ \tau\sum_{k=1}^N(U_h^k-U_{h,m}^k)^\top C(U_h^k-U_{h,m}^k) \right]^{1/2}. \] This is the exact time integral between their common right-constant reconstructions, up to arithmetic error. There is no reference space/time quadrature. The initial and forcing hat loads are integrated analytically; the latter is an explicit change from the fine-mesh forcing-load approximation in the old continuum-error notebook.

Spatial and temporal discretizations are shared by both solutions and therefore contribute no independent continuum-error floor. They still change the finite-dimensional experiment, so their influence on the observed curve is checked by refinement.

2 Parameters and private run

The defaults preserve the original horizon \(T=10^{-3}\), \(\kappa=4\), data and alpha values. coefficient_source = "package" uses the original tables and \(m=1,2,3,4\). Choosing "computed" reads the CSV and uses \(m=1,\ldots,8\). The base mesh is \(h=10^{-2}\) and the target step is \(10^{-5}\). Space, time, and both are independently halved. These are moderate problems suitable for a complete eigendecomposition.

workers schedules all alpha/order pairs together within each scenario. The eigensystem is reused across parameters, and an exact reference history is computed once per alpha/time grid. The size guards reject accidentally choosing the large dense problems of the original notebook.

4 Checks and diagnosis

The eigensystem is checked using generalized eigen-residuals and \(C\)-orthogonality. The independent rational root-product recurrence in the complete numerical eigenbasis checks the sparse implementation. At \(\alpha=2\), rational approximation is bypassed; its measured difference should be a numerical zero and provides an additional consistency control.

The diagnostic resolution ratio compares the product error with the larger of the sparse/product disagreement and the alpha=2 control. This is an empirical numerical indicator, not a certified error bound.

The measured quantity is the difference between exact-discrete and rational FEM/backward Euler solutions on the same grid.

Every primary rational trajectory uses the shifted sparse solver. The diagnostic root-product trajectory uses the complete numerical FEM eigenbasis.

6 Reproducing and interpreting the run

The full formulas and implementation are in fun/isolated_rational_convergence.Rmd. Run the regression checks with Rscript tests/check_isolated_m.R from the project environment.

The RStudio Knit button uses a custom renderer that keeps the report in its private run directory. From R, after loading the helpers, a fresh run is:

settings <- isolated_m_parameters()
# settings$diffusion <- 2
render_isolated_m_notebook(parameters = settings, workers = 4L)

Reload a saved run with render_isolated_m_notebook(run_id = "<saved ID>", execute = FALSE). Pass its modified parameters list as well if its scientific settings differ from the defaults. Metadata and package versions must match. Reloading regenerates the report and figures from saved data without overwriting the scientific results.

This study supports conclusions about the chosen discrete problem, physical data, coefficients, and tested orders. It does not measure the continuum error \(\|u-U_{h,m}^\tau\|\), certify uniform operator accuracy, or establish an asymptotic rational approximation rate from these finitely many orders.
